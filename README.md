# Isla Dorada — 8 Jobs to Clear His Name

A GTA 6-style open-world crime game built for make.fun's gta6-01 bounty (V8 fresh build).

Wowo, an ex-Sergeant dishonorably discharged, drives, steals cars, outruns the
IDPD and works 8 story jobs across a sunset island city to clear his name.
Drive + on foot, traffic + pedestrians, wanted levels + responding police,
missions, garage upgrades, radio, saves. Three.js, static files, no network.

Run it: `node serve.ts`, then open http://localhost:8080.
